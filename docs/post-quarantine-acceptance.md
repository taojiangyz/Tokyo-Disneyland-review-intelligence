# 隔离规则上线后的新问题验收

2026-10-04。使用更新后的本地 API、原有 dense 前 5 默认检索和 v2-language-evidence 提示词。在运行前固定 6 个新措辞问题，覆盖支付、天气、韩国游客服务、中国大陆游客餐饮，以及中英文 2035 年无数据筛选。这是小规模开发验收，不是独立盲测或泛化准确率评估。

## 结果

- 3 个检索探针分别测试 dense、hybrid、hybrid_rerank，使用明确包含富士山、导游、海盗船、缆车的韩文查询。所有入口返回结果均不含隔离 ID 221035459。
- 6/6 结构检查通过；4 次 Gemini 调用成功，2 个未来日期无证据问题跳过模型调用。
- Codex 阅读检查：6 个答案的语言符合问题。人工语义复核未开展。
- 支付：引用中有微信／支付宝使用受限的游客描述，但也将扫码入园问题混入支付回答，存在话题偏离。应更明确限定为游客报告，避免被误读为当前支付政策。
- 天气：支持下雨减少游玩、天气炎热的说法；夏季排队信息不能证明高温造成排队，放在高温段落中容易引起误读。
- 韩国服务：引用支持员工友善与受到尊重；同时提到预订平台服务和购买 DPA 的建议，应注意与园区员工服务的区分。
- 餐饮：新措辞检索到了认为价格不贵与认为较贵的两种意见，回答保留了分歧。但游客报告的历史价格不是当前官方价格；这一题成功不代表原第 5 题已被修复。
- 中英文无证据答案均明确说明缺少材料，没有编造回答。

## 后续优先项

优先收紧回答对问题主题的约束：支付、入园、订票平台、园区服务不要混为一谈；没有直接证据时可以少写，不为凑两到四条发现加入弱相关材料。修改后应保留本轮失败样例作回归，再另外准备未用于调整的新题。

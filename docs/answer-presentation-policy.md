# 回答展示规则修复

保留 v3-topic-focused 提示词，在生成服务返回答案前增加确定性的展示处理，版本 v1-localized-scope-ranking。

- 已知证据范围结尾标签根据问题语言本地化，避免中文答案出现英文标签。
- 对规则识别出的“most / worst / 排名 / 最常 / 最满意”等问题，在正文前加入说明：检索评论不能证明总体排名或频率。
- 不改写回答事实和引用，不通过机械替换修复语义问题。空输出不被包装成成功答案；无证据与降级响应不经过此展示处理。
- API generation trace 增加 output_policy_version，仅成功生成答案填写，便于区分原始模型生成与展示处理版本。模型调用日志的 prompt_version 仍为 v3。

验证：39 项测试通过。对上一轮保存的 26 个 API 答案做离线回放，引用序列全部保留，重复处理不会重复添加提示，4 个无证据响应保持原样。4 个排名类问题均添加前置限制，中文结尾不再出现已知英文标签。本轮没有 Gemini 调用，不产生新的模型 token 用量；没有重新进行真实 API 全流程或浏览器验收。

限制：语言选择沿用中英文规则；排名识别是规则匹配，不保证覆盖所有表达。前置提示不能证明正文没有过度概括，结尾本地化也不能保证全文语言正确。原餐饮检索遗漏、导游评论领域待核查、个别错字和引用归因仍保留为已知问题。

历史回归结果与用户人工评分没有改写。代码及文档已保存本地，尚未提交或推送 GitHub。服务重启后加载新代码。

下一步可整理发布候选说明，明确已实现的调用追踪、token／费用估算、回归与人工评估，以及已知限制；不要将开发测试集通过率写成生产准确率。
